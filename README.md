## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Performance and production
Next.js is the production entrypoint. Vite and the unmounted WebGL/video engines are experimental alternatives. The landing renders its heading before hydration and loads Canvas separately. The Canvas scene uses 1600 particles on every viewport and adapts drawing resolution and frequency to frame time.

Set NEXT_PUBLIC_RUM_ENDPOINT to your telemetry collector and NEXT_PUBLIC_RELEASE to the deployment revision before building to enable LCP/INP/CLS reporting. Only metric ID, name, value, viewport category and revision are transmitted; no contact content is collected. Without a collector configured, reporting is disabled.

Validation still requires physical Android/iOS, five cold 3G/CPU-throttled runs, production cache/compression headers and Preview review. The contact field has no submission backend.
